Creating Your First Token

Last updated: June 15, 2023 Written by: Alex TokenDesigner Category: Getting Started

Welcome to Ethora! This guide will walk you through the process of creating your first token using our Token Generator. By the end of this tutorial, you'll have a fully functional ERC-20 token deployed on the Ethereum blockchain.

Prerequisites

Before you begin, make sure you have:

  • A Web3 wallet (MetaMask, Trust Wallet, etc.)
  • Enough ETH in your wallet to cover gas fees (approx. 0.01-0.05 ETH)
  • Basic understanding of token concepts (name, symbol, supply)

Note: For test deployments, you can use the Goerli testnet to avoid spending real ETH.

Step 1: Access Token Generator

Navigate to the Token Generator section from the main dashboard or sidebar menu.

Step 2: Configure Token Parameters

Fill in the required fields for your token:

Basic Information

  • Token Name: The full name of your token (e.g. "My Crypto Token")
  • Token Symbol: The ticker symbol (e.g. "MCT")
  • Total Supply: The total number of tokens to create (e.g. 1000000)
  • Decimals: Precision of your token (usually 18 for standard tokens)

Warning: Token name and symbol cannot be changed after deployment!

Tokenomics

Set up your token's economic model:

  • Buy Tax: Percentage fee on purchases (e.g. 5%)
  • Sell Tax: Percentage fee on sales (e.g. 5%)
  • Max Wallet: Maximum tokens a wallet can hold (percentage of total supply)
  • Max Transaction: Maximum tokens per transaction

Liquidity

Provide initial liquidity for your token:

  • Liquidity ETH: Amount of ETH to add to liquidity pool
  • Liquidity Lock: Duration to lock liquidity (recommended 30+ days)
  • Marketing Wallet: Address to receive tax fees

Step 3: Review and Deploy

Double-check your token parameters in the preview section. When ready, click "Generate & Deploy Token".

Example Token Configuration 
{
  "name": "CryptoGem",
  "symbol": "GEM",
  "supply": 1000000,
  "decimals": 9,
  "taxes": {
    "buy": 5,
    "sell": 5
  },
  "limits": {
    "maxWallet": 2,
    "maxTx": 1
  },
  "liquidity": {
    "eth": 0.5,
    "lockDays": 365
  }
}

Step 4: Confirm Deployment

Your wallet will prompt you to confirm the transaction. Review gas fees and confirm to deploy your token contract.

Pro Tip: Deploy during low network congestion to save on gas fees. Check Ethereum Gas Tracker for current rates.

Step 5: Post-Deployment Steps

After successful deployment:

  1. Add your token to your wallet using the contract address
  2. Verify your contract on Etherscan
  3. Set up a liquidity pool on Uniswap
  4. Create a token logo and add to Trust Wallet

Troubleshooting

If you encounter issues:

  • Transaction fails: Try increasing gas limit by 20%
  • Token not showing: Add custom token using contract address
  • Wrong parameters: Double-check before deployment as changes aren't possible afterwards

For additional help, join our Community Discord where our team and community members can assist you.
